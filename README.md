# UtilityApp

A comprehensive mobile application designed to help you manage everyday tasks and calculations with ease.

## Features

UtilityApp is packed with practical utilities to simplify your daily life:

### 📋 To-Do List
- Create, organize, and track your daily tasks
- Mark tasks as complete to monitor your productivity
- Keep all your to-dos in one convenient location

### 🏋️ BMI Calculator
- Calculate your Body Mass Index (BMI) in seconds
- Track your health metrics
- Get insights into your fitness status based on your measurements

### 💰 Discount Calculator
- Quickly calculate discounts on purchases
- Find out the final price after applying percentage or fixed discounts
- Perfect for shopping and budgeting

### 🔧 And More
UtilityApp continues to expand with additional helpful tools and features designed to make everyday calculations and task management effortless.

## Getting Started

1. Download and install UtilityApp on your mobile device
2. Open the app and explore the various utilities available
3. Start using the tools to simplify your daily tasks

## Usage

Each utility is designed to be intuitive and user-friendly:
- Navigate between different tools using the app menu
- Input your data and let the app do the calculations
- Save or reference your results as needed

This app is built with modern mobile development practices to ensure smooth performance and a great user experience.
